2. Gambarkan diagram blok (shape) beserta arah panah aliran data dan jelaskan fungsi masing-masing komponen untuk: (A) Arsitektur Apache Flume Agent & Consolidation, dan (B) Mekanisme Operasi Tulis pada Apache HBase.

Kunci Jawaban Referensi (Berdasarkan Materi Kuliah):

A. Arsitektur Apache Flume (Single Agent & Consolidation):

[Web Server / Sumber Data] │ (Event) ▼ ┌─────────────────────────────────────────────────────────┐ │ FLUME AGENT │ │ ┌──────────┐ ┌───────────┐ ┌────────────┐ │ │ │ Source │ ────► │ Channel │ ────► │ Sink │ │ │ └──────────┘ └───────────┘ └────────────┘ │ └─────────────────────────────────────────────────────────┘ │ ▼ [HDFS / Storage] *Pola Consolidation (Multi-Agent): [Agent 1 (Avro Sink)] ──┐ [Agent 2 (Avro Sink)] ──┼──► [Agent 4: Avro Source -> Channel -> Avro Sink] ──► [HDFS] [Agent 3 (Avro Sink)] ──┘
  • Source: Komponen yang menerima/mengumpulkan data dari sumber eksternal (misal Web Server, Twitter/Syslog/Avro) dalam bentuk Event.
  • Channel: Penampung/antrean sementara (buffer seperti Memory/File Channel) yang menerima event dari Source sebelum diambil oleh Sink.
  • Sink: Komponen yang mengambil event dari Channel dan meneruskannya ke penyimpanan tujuan (seperti HDFS) atau ke Agent berikutnya.
  • Agent: Satu kesatuan proses JVM yang membungkus komponen Source, Channel, dan Sink.

B. Mekanisme Operasi Tulis (Write) pada Apache HBase:

[Client] ──(1. Put Request)──► [Region Server] │ ┌─────────────────────┴─────────────────────┐ ▼ ▼ (1) Tulis ke WAL (Write Ahead Log) (2) Salin ke MemStore (Memory Cache) (Untuk recovery jika gagal) │ ├──► (3) Kirim ACK ke Client ▼ (4) Jika penuh (Threshold), flush ke [HFile] di [HDFS DataNode]
  • ZooKeeper & .META Table: Saat pertama kali akses, Client menghubungi ZooKeeper untuk mengetahui lokasi Region Server yang menyimpan tabel katalog .META guna menemukan Region target.
  • WAL (Write Ahead Log / HLog): File log di HDFS tempat data baru pertama kali ditulis untuk menjamin pemulihan data (recovery) apabila Region Server mengalami kegagalan/mati mendadak.
  • MemStore: Write cache di memori (terdapat satu MemStore per Column Family dalam satu Region). Setelah data masuk ke sini, Client menerima konfirmasi berhasil (ACK).
  • HFile: Ketika kapasitas MemStore mencapai batas (threshold), data akan di-flush (disimpan permanen) ke disk HDFS dalam format HFile yang terurut berdasarkan KeyValue.
